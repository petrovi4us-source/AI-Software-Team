# AI Software Team

> Open Source Framework for AI-Driven Software Development

---

## О проекте

**AI Software Team** — это открытый фреймворк, предназначенный для организации совместной работы специализированных ИИ-агентов при разработке программного обеспечения.

Вместо одного универсального ассистента проект использует команду агентов, каждый из которых отвечает только за свою область компетенции.

Такой подход обеспечивает:

- более качественный анализ требований;
- прозрачный процесс разработки;
- разделение ответственности;
- воспроизводимость результатов;
- возможность автоматизации полного жизненного цикла разработки.

---

# Философия проекта

Разработка программного обеспечения состоит из множества различных дисциплин.

Например:

- интервьюирование заказчика;
- системный анализ;
- архитектурное проектирование;
- планирование;
- программирование;
- код-ревью;
- тестирование;
- DevOps.

Попытка поручить все эти задачи одному ИИ приводит к ухудшению качества результата.

Поэтому данный проект реализует принцип:

> **Один агент — одна ответственность.**

Каждый агент является специалистом только в своей области.

---

# Цели проекта

Создать открытую библиотеку профессиональных системных промптов, позволяющую организовать команду ИИ-агентов, выполняющих полный цикл разработки программного обеспечения.

Проект должен быть:

- модульным;
- расширяемым;
- независимым от конкретной LLM;
- пригодным для ручной и автоматизированной работы;
- совместимым с современными агентными платформами.

---

# Принципы

Проект придерживается следующих принципов.

## Разделение ответственности

Каждый агент выполняет только одну роль.

## Явные артефакты

Каждый этап разработки имеет четко определенный входной и выходной документ.

## Проверяемость

Любое решение должно иметь объяснение.

## Повторяемость

Одинаковые входные данные должны приводить к сопоставимым результатам.

## Независимость

Каждый агент может быть заменен без изменения остальных компонентов системы.

# Жизненный цикл проекта

Разработка проходит последовательно.

1. Интервьюирование пользователя.
2. Формирование требований.
3. Разработка спецификации.
4. Проектирование архитектуры.
5. Планирование.
6. Реализация.
7. Код-ревью.
8. Тестирование.
9. Подготовка к развертыванию.

Каждый следующий этап использует только утвержденный результат предыдущего.
